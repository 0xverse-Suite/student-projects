## Verified controls

- Every course repository is public with default branch `main`.
- `main` requires a pull request, one Code Owner review, resolved conversations, and blocks force pushes and deletion.
- Course teams have `push` only on their matching repository.
- Tutor teams have `maintain`; academy mentors have `triage`; admins have `admin`.
- The general `students` team has no automatic write access to course repositories.
- Every course has a linked Project and the standard academic Workflow.
- Every course has a README, CONTRIBUTING guide, tutor guide, student guide, assignment form, PR template, CODEOWNERS, and `.gitignore`.

## Current blockers

1. No real course tutor usernames have been supplied.
2. No real student usernames, course enrollments, or cohort identifier have been supplied.
3. Documentation changes in protected existing repositories require independent review.
4. Runtime-specific CI checks cannot be required until each course adopts a toolchain and reliable checks.

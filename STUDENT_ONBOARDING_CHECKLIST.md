# Student Onboarding Checklist

- [ ] Created a GitHub account; a professional, reusable username is encouraged.
- [ ] Added and verified an email address in GitHub settings.
- [ ] Configured Git with a GitHub-connected email or GitHub `noreply` email.
- [ ] Confirmed `git config --global user.name` and `git config --global user.email`.
- [ ] Accepted the 0xVerse Suite organization invitation.
- [ ] Joined only the team or teams for enrolled courses.
- [ ] Opened the correct course repository and confirmed access.
- [ ] Opened the course Project and found assigned Issues.
- [ ] Read the repository README, contribution guide, and student guide.
- [ ] Understands Issue requirements and acceptance criteria.
- [ ] Understands branch and commit basics where applicable.
- [ ] Understands how to submit a pull request or discipline-specific review submission.
- [ ] Knows how to read tutor feedback, revise the same submission, and request re-review.
- [ ] Understands that DONE and portfolio-ready are separate quality decisions.
- [ ] Will never commit passwords, API keys, tokens, private information, restricted datasets, or unlicensed assets.
- [ ] Completed the supervised first-assignment practice workflow.

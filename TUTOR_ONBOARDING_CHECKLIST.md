# Tutor Onboarding Checklist

- [ ] GitHub account is active and username is confirmed.
- [ ] 0xVerse Suite organization invitation accepted.
- [ ] Added to the correct `<course>-tutors` team as a member or maintainer.
- [ ] Course repository opens and `maintain` access is verified.
- [ ] Course Project opens and can be updated.
- [ ] Read `TUTOR_GUIDE.md` and the cohort/assignment standard.
- [ ] Can create an Issue from the assignment template.
- [ ] Can set Cohort, Priority, Assignment Type, Due Date, Assignee, and Workflow.
- [ ] Understands how to assign only enrolled students.
- [ ] Can review pull requests or discipline-appropriate submissions.
- [ ] Can request specific revisions and move work to CHANGES REQUESTED.
- [ ] Can approve completed work and move it to DONE.
- [ ] Understands the portfolio-ready standard and publication checks.
- [ ] Knows to escalate access, security, privacy, licensing, or organization changes to `@0xverse-Suite/admins`.
- [ ] Will not change organization security, branch protection, or team permissions without admin approval.
